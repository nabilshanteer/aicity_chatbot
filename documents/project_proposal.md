# **Citizens Advice Information Retrieval Chatbot Specification:**

# **Problem Statement**

Citizens' Advice services are experiencing a growing demand for support. As a result, staff are often unable to assist as many people as quickly as needed. It is difficult to access reliable, case-specific information because relevant data is distributed across multiple trusted sources (e.g., housing policies, local council regulations, guidance documents). During peak-times, this fragmentation may lead to the following issues:

1. Time-consuming information retrieval.  
2. Rushed and therefore, inconsistent advice quality.  
3. Impacted decision-making.  
4. A negatively impacted client experience.

# **Proposed Solution**

This project proposes an AI-enabled advisory assistant that consolidates verified information from multiple trusted sources and delivers context-aware, relevant responses to support service user inquiries.

The system will:

1. Retrieve information from pre-approved, trusted datasets  
2. Identify the most relevant content for a given query  
3. Generate clear, contextualised responses  
4. Provide source-backed answers to ensure transparency and trust

# **Key Features**

* **Multi-Source Consolidation:** Automatically cross-references legal documents, council policies, and guidance notes.  
* **Tailored Responses:** Tailors answers using case specifics and ongoing conversation history.  
* **Trusted Source Grounding:** Eliminates hallucinations by relying strictly on verified datasets and displaying explicit source links.  
* **Adjustable Response Depth:** Features a toggle for Quick (minimal), Standard (balanced), or Deep (extensive) search and generation modes.  
* **Conversation Memory:** Retains case context to allow for seamless, natural follow-up questions.  
* **Voice Input (Optional):** Speech-to-text integration for enhanced accessibility and hands-free use.  
* **Security & Compliance:** Ensures UK GDPR compliance through strict data minimisation, end-to-end encryption, and role-based access control.

# **Summary**

In conclusion, this AI-powered advisory assistant addresses the inefficiency caused by scattered data by providing a secure, centralised, and context-aware platform. By grounding all responses strictly in verified sources and prioritising UK GDPR compliance, the tool empowers staff to deliver faster, more consistent, and highly reliable guidance to service users.
